# Pokédex

Um aplicativo simples para exibir informações sobre Pokémon usando a API PokeAPI.

## Recursos

- Busca por nome ou número do Pokémon.
- Exibe número, nome e imagem do Pokémon.
- Botões de navegação para o próximo e o Pokémon anterior.

## Como usar

1. Clone o repositório:

    ```bash
    git clone https://github.com/lggustavodev/Pokedex.git
    ```

2. Navegue até o diretório do projeto:

    ```bash
    cd Pokedex
    ```

3. Abra o arquivo `index.html` no seu navegador preferido.
